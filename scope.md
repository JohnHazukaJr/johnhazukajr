# Project Scope Statement: Personal Webpage

## Project Purpose

 The purpose is twofold: apply the project management principle of scoping by defining clear boundaries before building, and produce a well-structured semantic HTML document that introduces me to the course while practicing foundational web development skills.

## Description

The project will deliver a single static HTML page (`index.html`) and a supporting scope statement (`scope.md`). The webpage will include my name, my major in Computing Applications, two paragraphs describing my career and course goals, an unordered list of hobbies and interests, and a hyperlink to my GitHub profile at https://github.com/JohnHazukaJr. The page will use semantic HTML elements only, with no custom styling or additional pages.

## Desired Results

- A valid HTML5 document with a title, h1, h2, at least two paragraphs, an unordered list with at least three items, and a GitHub hyperlink
- Content that accurately represents John Hazuka, my CMPA studies, my goal of building a tech career that supports home ownership and starting a family, and my personal interests
- A scope statement that documents purpose, description, desired results, and exclusions per PMUPM Chapter 3
- Both files packaged in a single zip file ready for course submission

## Exclusions

- No JavaScript or interactive features
- No images, videos, or embedded media
- No additional HTML pages or multi-page navigation
- No external frameworks (Bootstrap, React, etc.)
- No contact forms, backend services, or deployment configuration
